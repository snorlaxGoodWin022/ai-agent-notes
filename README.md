## About

这是我在学习 AI Agent 开发过程中的个人笔记仓库。内容以实操为主，概念服务于实践，跟着课程和实战项目逐步深入。

## 笔记约定

- 每个主题一个文件夹，文件夹名用英文，如 `tool-use`、`multi-agent`
- 笔记统一用 Markdown（`.md`），按需使用代码块、流程图、截图
- 图片放在 `assets/` 下，按文件夹归类
- 命名规范参考：`01-topic-name.md` 或直接 `topic-name.md`，保持可读即可
