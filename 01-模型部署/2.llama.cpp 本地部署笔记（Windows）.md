# llama.cpp 本地部署笔记（Windows）

## 一、下载安装 llama.cpp

### 方式一：winget 安装（推荐，最简单）
```powershell
winget install llama.cpp
```
安装后自动更新。

### 方式二：GitHub Releases 下载免编译包
官方 Releases：https://github.com/ggml-org/llama.cpp/releases

根据电脑配置选择对应的 zip 包：
- **纯 CPU 用**：`llama-bxxxx-bin-win-cpu-x64.zip`
- **NVIDIA 显卡用**：`llama-bxxxx-bin-win-cuda-12.4-x64.zip`
  - 同时下载 `cudart-llama-bin-win-cuda-12.4-x64.zip`，解压后把 DLL 文件放到 llama.cpp 目录下

下载后解压到任意目录（如 `D:\llama.cpp`），解压后能看到 `llama-cli.exe`、`llama-server.exe` 等文件。

验证安装：
```powershell
llama-cli --version
```


## 二、国内镜像下载模型（解决下载慢）

llama.cpp 只支持 **GGUF 格式**的模型。国内用户推荐以下两个镜像站：

### 镜像站点
| 镜像站     | 地址                      | 说明                        |
| ---------- | ------------------------- | --------------------------- |
| HF-Mirror  | https://hf-mirror.com     | Hugging Face 国内镜像，稳定 |
| ModelScope | https://www.modelscope.cn | 阿里达摩院出品，国内速度快  |

### 使用 HF-Mirror 下载（示例：Qwen2.5-7B）
```powershell
# 安装 hfd 下载工具
pip install hf-transfer

# 设置镜像环境变量
$env:HF_ENDPOINT = "https://hf-mirror.com"

# 下载模型（GGUF 格式）
huggingface-cli download Qwen/Qwen2.5-7B-Instruct-GGUF --local-dir ./models/qwen2.5-7b
```

### 使用 ModelScope 下载
```powershell
pip install modelscope
modelscope download --model Qwen/Qwen2.5-7B-Instruct-GGUF --local_dir ./models/qwen2.5-7b
```


## 三、llama.cpp 优缺点

### 优点
- **轻量高效**：纯 C/C++ 实现，无外部依赖，资源占用极低
- **CPU 优化出色**：利用 SIMD 指令集（AVX2、NEON）和多核并行，CPU 上推理速度快
- **GPU 可选加速**：支持 CUDA、Metal、Vulkan 等多种后端
- **量化支持好**：GGUF 格式支持 1.5-8 bit 量化，内存占用减少 4-10 倍
- **高度可配置**：`-ngl`、`-t`、`-c` 等底层参数可精细调优

### 缺点
- **命令行操作**：无图形界面，对新手不友好
- **不支持批处理**：一次只能处理一个请求，高并发场景表现不佳
- **静态分配**：并发能力弱，多请求场景下不如 vLLM


## 四、启动模型

### 交互式对话（命令行聊天）
```powershell
llama-cli -m ./models/qwen2.5-7b/qwen.gguf -i
```
进入后直接输入问题，输入 `/bye` 退出。

### 单次问答
```powershell
llama-cli -m ./models/qwen2.5-7b/qwen.gguf -p "你好，介绍一下你自己"
```

### 启动 API 服务（HTTP 调用）
```powershell
llama-server -m ./models/qwen2.5-7b/qwen.gguf --host 127.0.0.1 --port 8080 -c 4096
```
服务启动后，通过 `http://localhost:8080` 访问。

测试 API：
```powershell
curl http://localhost:8080/completion -H "Content-Type: application/json" -d '{"prompt": "你好", "max_tokens": 100}'
```


## 五、常用启动参数

| 参数                    | 说明                            |
| ----------------------- | ------------------------------- |
| `-m <路径>`             | 指定模型文件路径                |
| `-i`                    | 交互模式（对话）                |
| `-p "<提示词>"`         | 单次问答的提示词                |
| `-c <数字>`             | 上下文长度（默认 512）          |
| `-t <数字>`             | 线程数（CPU 核心数）            |
| `--n-gpu-layers <数字>` | 将多少层放到 GPU（-1 表示全部） |
| `--host <IP>`           | 服务监听地址                    |
| `--port <端口>`         | 服务监听端口                    |


## 六、补充说明

### 模型存放位置
建议统一放在 `./models/` 目录下，方便管理。

### 关闭模型
- 交互模式：输入 `/bye` 退出
- API 服务：按 `Ctrl+C` 终止

### 验证模型是否正常
```powershell
llama-cli -m ./models/xxx.gguf -p "1+1="
```
能正常输出结果即部署成功。

### 注意事项
- 模型必须是 **GGUF 格式**，其他格式需先转换
- 如果模型文件较大，首次加载可能需要几秒到几十秒
- GPU 加速版需要安装对应的 CUDA Toolkit
