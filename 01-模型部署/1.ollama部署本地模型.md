# Ollama 本地部署笔记

## 一、下载安装 Ollama

**官方下载地址：** https://ollama.com/download 

### Linux
```bash
curl -fsSL https://ollama.com/install.sh | sh
```
安装完成后验证：
```bash
ollama --version
```


### macOS（Homebrew）
```bash
brew install ollama
```


### Windows
- 方式一：下载 OllamaSetup.exe 安装包双击运行
- 方式二：PowerShell 运行
```powershell
iwr https://ollama.com/install.ps1 -useb | iex
```


安装后 Ollama 服务会自动启动，API 服务默认运行在 `http://localhost:11434`。


## 二、选择并下载模型

模型列表查询：https://ollama.com/library

**下载模型命令：**
```bash
ollama pull <模型名称>
```


### 示例：下载 DeepSeek-R1 7B 模型
```bash
ollama pull deepseek-r1:7b
```


> 常用模型参考：`llama3.2`、`gemma4`、`qwen:7b`、`mistral` 等


## 三、查看已下载的模型

```bash
ollama list
```


输出示例：
```
NAME               ID              SIZE      CREATED
deepseek-r1:7b     xxxxxxxx        4.2 GB    2025-03-15
```


## 四、在命令行运行模型

### 交互式运行（进入聊天模式）
```bash
ollama run deepseek-r1:7b
```


进入后直接输入问题即可对话，输入 `/bye` 退出。

### 单次问答（非交互）
```bash
ollama run deepseek-r1:7b "你的问题"
```


### 管道输入
```bash
cat 文件.txt | ollama run deepseek-r1:7b "总结这段内容"
```



## 五、验证模型是否正常运行

### 方法一：查看已下载模型列表
```bash
ollama list
```


### 方法二：查看正在运行的模型
```bash
ollama ps
```


### 方法三：直接运行测试
```bash
ollama run deepseek-r1:7b "你好"
```
若能正常返回回答，说明部署成功。


## 六、关闭模型

### 方法一：在交互会话中输入
```
/bye
```


### 方法二：停止后台运行的模型
```bash
ollama stop deepseek-r1:7b
```


### 方法三：查看所有运行中的模型并停止
```bash
ollama ps          # 查看正在运行的模型
ollama stop <模型名>  # 停止指定模型
```



## 七、其他常用命令速查

| 命令                 | 用途               |
| -------------------- | ------------------ |
| `ollama pull <模型>` | 下载模型（不运行） |
| `ollama list`        | 列出所有本地模型   |
| `ollama ps`          | 查看正在运行的模型 |
| `ollama stop <模型>` | 停止运行中的模型   |
| `ollama rm <模型>`   | 删除模型释放空间   |
| `ollama serve`       | 启动 Ollama 服务   |

---

**小贴士：**
- 模型默认存储在 `~/.ollama/models`，可通过环境变量 `OLLAMA_MODELS` 自定义路径
- `ollama run` 如果本地没有该模型，会自动先执行 `pull` 下载
