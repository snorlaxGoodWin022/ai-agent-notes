# Ollama 模型调优参数笔记（实操版）

## 一、参数总览

| 参数                  | 类型  | 作用                    | 调大效果                   | 调小效果               | 推荐范围 | 适用场景   |
| --------------------- | ----- | ----------------------- | -------------------------- | ---------------------- | -------- | ---------- |
| **temperature**       | float | 控制随机性              | 更发散、更有创意、容易胡编 | 更稳定、更保守、更确定 | 0.1~0.4  | 代码/问答  |
| **top_p**             | float | 控制候选词概率范围      | 词汇更丰富、更开放         | 更保守、集中高概率词   | 0.7~0.9  | 通用场景   |
| **top_k**             | int   | 限制候选词数量          | 选择更多词（更发散）       | 选择更少词（更稳定）   | 20~50    | 辅助调优   |
| **repeat_penalty**    | float | 防止重复输出            | 减少重复、避免复读         | 容易重复               | 1.05~1.2 | 长文本生成 |
| **presence_penalty**  | float | 鼓励新内容              | 更容易换话题               | 更容易重复主题         | 0~0.6    | 创意写作   |
| **frequency_penalty** | float | 减少词频重复            | 控制用词重复               | 可能复读               | 0~0.5    | 文本优化   |
| **num_predict**       | int   | 最大生成长度（token数） | 输出更长、耗时增加         | 输出更短、更快         | 100~300  | 所有场景   |
| **num_ctx**           | int   | 上下文长度（记忆容量）  | 记更多内容、占资源         | 容量变小               | 2048     | 小模型固定 |
| **stop**              | array | 停止生成条件            | 控制输出结束位置           | 无控制                 | 按需设置 | 格式控制   |
| **seed**              | int   | 随机种子（复现）        | 固定输出可复现             | 每次不同               | 任意值   | 测试/对比  |


## 二、参数分组速记

### 控制「胡不胡说」（输出质量）
- **temperature**：核心参数，调高更随机，调低更稳定
- **top_p**：配合 temperature 使用，调低让输出更集中
- **top_k**：辅助限制候选词范围

### 控制「复不复读」（输出多样性）
- **repeat_penalty**：惩罚重复词，越大越不重复
- **frequency_penalty**：按词频惩罚重复词
- **presence_penalty**：鼓励模型引入新话题

### 控制「长不长」（输出长度）
- **num_predict**：限制生成长度

### 控制「记不记得住」（上下文）
- **num_ctx**：上下文窗口大小


## 三、实操：在 Ollama 中调参

### 方式一：使用 Modelfile（永久生效）

创建 Modelfile 文件：
```dockerfile
FROM deepseek-r1:7b

PARAMETER temperature 0.2
PARAMETER top_p 0.85
PARAMETER repeat_penalty 1.1
PARAMETER num_predict 200
PARAMETER num_ctx 2048
```

创建自定义模型：
```bash
ollama create my-model -f ./Modelfile
```

运行自定义模型：
```bash
ollama run my-model
```

### 方式二：命令行临时传参（单次生效）

```bash
ollama run deepseek-r1:7b --temperature 0.1 --top_p 0.8 --repeat_penalty 1.1
```

### 方式三：API 调用传参（最灵活）

```bash
curl http://localhost:11434/api/generate -d '{
  "model": "deepseek-r1:7b",
  "prompt": "你好",
  "stream": false,
  "options": {
    "temperature": 0.2,
    "top_p": 0.85,
    "repeat_penalty": 1.1,
    "num_predict": 200
  }
}'
```


## 四、场景推荐配置

### 配置一：稳定通用版（日常问答、翻译）
```json
{
  "temperature": 0.2,
  "top_p": 0.85,
  "repeat_penalty": 1.1,
  "num_predict": 200,
  "num_ctx": 2048
}
```

### 配置二：写代码专用（精确、不出错）
```json
{
  "temperature": 0.1,
  "top_p": 0.8,
  "repeat_penalty": 1.1,
  "num_predict": 300
}
```

### 配置三：创意文案（小模型慎用，容易跑偏）
```json
{
  "temperature": 0.7,
  "top_p": 0.95,
  "num_predict": 300
}
```

### 配置四：长文本摘要（需要记忆和防止复读）
```json
{
  "temperature": 0.3,
  "top_p": 0.9,
  "repeat_penalty": 1.15,
  "num_predict": 500,
  "num_ctx": 4096
}
```


## 五、调参黄金法则

| 问题现象                   | 调整方向                           |
| -------------------------- | ---------------------------------- |
| 回答胡说八道               | 降低 **temperature**（0.1~0.2）    |
| 回答太死板、不自然         | 调高 **temperature**（0.6~0.8）    |
| 一直在重复同一句话         | 调高 **repeat_penalty**（1.1~1.2） |
| 输出到一半就断了           | 调大 **num_predict**（300~500）    |
| 记不住前面聊的内容         | 调大 **num_ctx**（4096 以上）      |
| 每次回答都不一样，无法复现 | 固定 **seed** 值                   |


## 六、查看当前模型参数

```bash
ollama show deepseek-r1:7b --parameters
```

---

**一句话总结：调参核心是控制随机性与稳定性的平衡，temperature 和 num_predict 最常用，其他参数按需微调。**
